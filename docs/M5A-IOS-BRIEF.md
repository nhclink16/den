## Project
- `apps/ios`, generated from a committed `project.yml` with XcodeGen so the `.xcodeproj` is reproducible (install XcodeGen via brew on the iMac). Bundle id `app.denchat.ios`, display name `Den`, iOS 26 minimum, Swift 6, SwiftUI, strict concurrency. Automatic signing with Nicholas's team; the first `xcodebuild -allowProvisioningUpdates` creates the Apple Development certificate and profile. If signing fails because no team is selectable, stop and say exactly what is missing.
- API client generated from `/openapi.json` with Apple's Swift OpenAPI Generator, regenerated by a script from the live server. Types in `den-core` are the contract; do not hand-write models that exist in the spec.
- Session: bearer token in the Keychain per origin, WebSocket via `POST /auth/ws-ticket` as the desktop does. One origin in M5a; structure the store per origin so M5c's switcher is additive.
- Icon: Doorway d on the dark squircle at 1024, via an asset catalog. Launch screen: solid `bg` with the mark centered.

## Look and feel
- Themes come from `GET /users/me/appearance` and the shared families in `docs/THEMES.md`. Map roles to SwiftUI: `bg` window background, `bg2` grouped section background, `bg3` controls, `line` separators, `ink`/`ink2`/`ink3` primary/secondary/tertiary text, `accent` tint and all "live" indicators, `success`, `danger`. Follow Mode light/dark/system. Fonts: use the theme's body family if it is bundled (bundle the families from the built-ins as OTF/TTF with their licenses), else fall back to system; display font for room titles only; mono for timestamps and codes.
- Liquid Glass: the tab bar and toolbars use the iOS 26 glass materials (`.glassEffect`, glass toolbars, scroll-edge effects) with the theme accent as tint. Do not fake glass with blur views.
- Structure: a tab bar with `Rooms`, `Inbox`, `Search`, `Settings`. Rooms is a list grouped by category with unread counts and mention dots in accent, DMs in their own group, the hangout row showing who is in it. Tapping a room pushes the conversation. On iPad, `NavigationSplitView` with the same list as the sidebar.
- Conversation: messages grouped by author within five minutes like the web, day separators, a `new` marker at the last read position, markdown via `AttributedString(markdown:)` with mentions rendered as accent pills, reply reference above a reply, reactions row with tap to toggle and long-press for the quick set, images and video inline (AVPlayer, `playsinline`, scrubbing), files as a card. Long-press a message: Reply, React, Copy, Edit (own), Delete (own or admin). Composer: text field with Shift-less send button, attachment button opening PhotosPicker and Files, upload progress ring on the pending chip, replies shown above the field. Typing indicators below the list; presence dots on avatars.
- Inbox: same grouping as the web, tap to open the room at the first unread. Search: server search with a scope picker. Settings: Appearance (family cards drawn with the palette, mode), Notifications (mentions, DMs, followed rooms), Account (name, log out), Machines and Access read-only lists for now.
- Haptics on send and on reaction. Pull to refresh reloads the tail. Offline: show cached messages from the last session with a quiet `offline` chip; do not build a sync engine.

## Push
- Server: `POST /devices` registers `{ platform: "ios", token, app_version }` for the session's user; `DELETE /devices/{id}` on logout. Send APNs pushes for the same events that produce `notification` over the socket (mention, DM, followed room) using token-based auth with the `.p8` key from `DEN_APNS_KEY_PATH`, `DEN_APNS_KEY_ID`, `DEN_APNS_TEAM_ID`, topic `app.denchat.ios`, sandbox or production by build.
