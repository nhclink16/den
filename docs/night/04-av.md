# Track 4: microphone and camera controls

Branch `feat/av-settings`. Read `docs/night/README.md` and `docs/M3-NOTES.md`.

From Nicholas in #ideas: **"Is there a way that we can add adjustments to mic and webcam settings?"**

Settings > Voice currently offers device pickers and a level meter and nothing else. Add real controls, all applied live to the running call:

**Microphone** — input gain as a slider backed by a `GainNode`; echo cancellation, noise suppression and auto gain as switches, applied via `applyConstraints` on the live track so toggling does not drop the call; the existing meter reflects gain so the effect is visible.

**Camera** — resolution (auto, 720p, 1080p) and frame rate (24, 30, 60) where the device supports them, read from `getCapabilities` and applied with `applyConstraints`; a mirror toggle affecting only your own preview; and a live preview in Settings so choices can be judged without joining a call. Offer brightness, contrast and saturation only where `getCapabilities` actually reports them, and hide the control otherwise rather than showing one that does nothing.

Persist everything per device id in the user's account so it follows them, reusing the appearance sync pattern rather than inventing a new one.

Two related ideas from the same channel are **out of scope tonight**, but leave the seams clean for them and say in the PR where they would attach: soundboards and voice mods. Both are per-user audio inserted into the outgoing track, which is the same graph the gain node creates.

Do not touch anything Fable owns under `apps/web/src/ui/Appearance*.svelte`.

PR title "Voice: real microphone and camera controls". Before and after of Settings > Voice, and a capture of changing resolution mid-call without dropping it. Post `[astra-av] PR open` to fable.
